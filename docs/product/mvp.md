# MVP Definition

## Minimum learning outcome

Demonstrate that an agentic delivery workflow can be explicit, grounded, stateful, governed, observable, evaluated, and deployable without requiring a paid external integration.

## Included

- One business scenario
- Four user roles
- One deterministic model policy
- One local knowledge corpus
- One governed tool action
- One approval workflow
- One asynchronous worker path
- One golden set and baseline
- Local and GCP development profiles

## Excluded

- General-purpose autonomous agent
- Multiple production model providers
- Real voice, workflow automation, ticketing, or MCP connections
- Model training or fine-tuning
- Commercial tenant, billing, subscription, or support features
- Production operations

## MVP guardrail

A requested addition belongs in the MVP only if it is required to complete the primary journey, validate a stated acceptance criterion, or demonstrate a listed architectural quality with evidence.
