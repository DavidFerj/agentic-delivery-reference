# Outcome Metrics

| Dimension | Metric | Target for first reference release |
| --- | --- | --- |
| Value | Main workflow completion | 100% for supported golden cases |
| Quality | Required deterministic evaluation pass rate | 100% |
| Safety | Unauthorized sensitive tool executions | 0 |
| Reliability | Duplicate side effects under retries | 0 |
| Traceability | Executions with complete correlation | 100% |
| Delivery | Clean local setup success | Pass on supported environment |
| Demonstrability | Main demo duration after setup | Under 10 minutes |
| Cost | Paid dependency required for local mode | None |
| Evidence | Implemented capabilities with complete registry links | 100% |

Metrics are calculated from synthetic workflow and CI evidence. They are engineering and learning targets, not claims about production user value.
